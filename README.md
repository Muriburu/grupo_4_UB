# Creación de una nueva clasificación de enfermedades raras mediante técnicas de clustering
Este repositorio contiene los scripts, datos y visualizaciones empleados en el trabajo final del curso:

**Ciencia de los Datos (Data Science), Aplicaciones en Biología y Medicina con Python y R**  
_Código del curso: 007661.2425.Abril.IL3.000.0 - IL3 Universidad de Barcelona_

## 📂 Estructura del repositorio

- `data/`: Datos descargados y procesados a partir de Orphadata.
- `scripts/`: Cuadernos Jupyter con análisis exploratorio, obtención y transformación de datos y clustering.
- `README.md`: Este documento.

## 📋 Descripción del trabajo

El objetivo del proyecto es realizar un análisis exploratorio y agrupamiento de enfermedades raras según sus términos fenotípicos (HPO), utilizando técnicas de reducción de dimensionalidad y algoritmos de clustering (K-means, BIRCH, HDBSCAN, OPTICS y Agglomerative). Se lleva a cabo una transformación de datos cualitativos a formato numérico y se evalúan distintas configuraciones para identificar patrones relevantes.
